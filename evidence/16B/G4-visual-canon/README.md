# G4 visual canon

The accepted shared shell remains authoritative: 58px warm-white Header, subtle divider, warm paper background, three radius levels, restrained persimmon orange and one formal Living Companion. Existing watercolor assets are atmospheric only and never cover editor copy, questions, controls or video media.

Browser measurements at 1920 and 1440 showed no horizontal overflow on all six target routes. Scrollbar-adjusted pages reported `scrollWidth == documentElement client width` (1905/1425); non-scrolling pages reported exact 1920/1440.

No global sidebar was added. The only left rail remains AI Workspace conversation memory; full learning pages use their existing content layout.
