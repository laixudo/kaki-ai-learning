# 柿子智学最终交付包使用说明

本交付包已经把 React 主前端、FastAPI 后端、AI 学习工作区、注册画像对话与《丰穗秘境》学习冒险整合为一个工程。队友无需使用 GitHub，也不需要手工拼接多个项目。

## 一键启动

环境要求：Windows 10/11、Python 3.11、Node.js 20 或更高版本，并能使用 `py`、`npm`。

1. 解压整个压缩包，路径尽量不要包含特殊符号。
2. 双击或在 PowerShell 中运行根目录 `start.ps1`。
3. 首次启动会自动创建 Python 虚拟环境并安装前后端依赖；完成后自动打开 `http://127.0.0.1:5174/`。
4. 关闭服务时运行 `stop.ps1`。

交付包不包含任何人的密钥或登录信息。首次正式启动前需在根目录安全创建本机 `.env`，设置 `MODE=production`、强随机 `SECRET_KEY`、受支持的非 mock Provider，以及对应的本机密钥；密钥不得写入源码或交付证据。

## 正式用户入口

主导航只有八项：

1. 首页
2. AI 学习
3. 我的学习
4. 资料库
5. 学习笔记
6. 学习产物
7. 练习与测评
8. 学习画像

兼容关系：`/qa` 自动进入 `/ai-learning`；旧智能体页进入 AI 学习；旧视频页进入学习产物；旧报告页进入学习画像。`app.html#tutor` 只保留遗留只读提示，不再作为开发入口。

## 注册后的“认识你”

新用户注册后进入独立画像引导页。页面只保留柿小吉、逐题自然对话、输入框、进度以及跳过/稍后/完成操作。底层任务类型固定为 `profile_onboarding`，会话与普通聊天隔离；每次只问一个问题，不确定信息必须确认。用户确认后同时保存结构化字段、原话、来源、可信度、确认状态和可读画像摘要。

## AI 学习与丰穗秘境

`/ai-learning` 直接挂载现有 AI 工作区内核，没有 iframe，也没有复制第二套聊天逻辑。普通聊天、AI 导师、历史会话、资料上传、OCR、语音输入、智能体产物、记忆、画像、学习图谱和资料库快捷入口继续使用原接口。

AI 学习工作区侧栏的“拾光漫游”从当前真实问题进入动态学习冒险。进入前会显示主题确认与内容来源；游戏使用既有 `harvest_adventure` 状态机，提供动态地点、自由选路、答错补救、敌人完整生命周期、Boss 三阶段、刷新恢复、真实奖励领取/查看/装备和烟花结算。奖励不会自动安装，始终由用户主动决定。

场景、角色、物件、动效与落位详见 `docs/HARVEST_ADVENTURE_ART_AND_RESOURCE_GUIDE.md`；机器可读清单位于 `frontend/public/ai-workspace/assets/adventure/resource-manifest.json`。

## 常见问题

- 首次安装较慢：OCR、语音和 AI 依赖体积较大，请保持网络连接。
- 8001 或 5174 端口被占用：先运行 `stop.ps1`，再确认占用端口的旧进程归属。
- 页面能打开但真实 AI 不回答：演示模式只用于立即体验；真实调用必须在 `.env` 中配置模型提供商和对应密钥。
- 语音识别不可用：Chrome/Edge 会优先尝试浏览器语音能力；本地 ASR 依赖会在首次安装时配置。
- 不要把 `.env`、`backend/*.db`、`node_modules`、`.venv311` 或日志重新压缩转发。
